# Hướng Dẫn Sử Dụng SWITCH VIỆT HÓA

## 1. Trang chủ và cách di chuyển
- Mở app sẽ vào Trang chủ. Ô lớn màu đỏ là Kho Việt Hóa, bốn ô bên phải là Đã Tải, Chia Sẻ, Hướng Dẫn, Cài Đặt.
- Dùng D-pad hoặc cần trái để chọn ô, bấm A để mở.
- Hàng Mới cập nhật ở dưới hiện các game vừa có bản việt hóa. Chọn một game rồi bấm A để xem chi tiết ngay.
- Trong từng mục, bấm L hoặc R để chuyển sang mục bên cạnh. Chấm đỏ ở góc trên bên phải cho biết bạn đang ở mục nào.
- Bấm B để quay về Trang chủ. Đang ở thư mục con trong Đã Tải thì B là lên thư mục cha.
- Ở Trang chủ: bấm Y để tìm game ngay, bấm - để mở Đã Tải.
- Màn hình cảm ứng: chạm một lần để chọn, chạm lần nữa để mở. Chạm vào tên mục ở góc trên bên trái để về Trang chủ.
- Góc trên bên phải hiện thông báo khi app đang tải danh sách game hoặc đang tải patch, kèm phần trăm và tốc độ.
- Thanh dưới cùng: pin, Wi-Fi, giờ và RAM đang dùng ở bên trái, các nút bấm được ở bên phải.

## 2. Tìm và lọc game
- Vào Kho Việt Hóa, game hiện dạng lưới ảnh bìa 5 cột. Hàng dưới ló ra một phần để biết còn game phía sau.
- Nhãn xanh ĐÃ TẢI trên ảnh bìa: patch đã tải và giải nén trên thẻ SD. Nhãn xám SẮP CÓ: game chưa có file patch.
- Dưới ảnh bìa là dung lượng patch và phiên bản. Game có nhiều bản patch sẽ ghi số bản, ví dụ 3 bản.
- Bấm Y (hoặc chạm ô tìm kiếm) để gõ tên game hoặc Title ID cần tìm. Bấm ZL để xóa tìm kiếm.
- Bấm X (hoặc chạm nút Thể loại) để mở bảng chọn thể loại. Mỗi ô ghi sẵn số game của thể loại đó.
- Trong bảng thể loại: dùng D-pad chọn ô, bấm A để lọc, bấm B để đóng. Thể loại đang lọc có dấu tick.
- Đang lọc thì nút Thể loại chuyển màu đỏ và ghi tên thể loại. Chọn Tất cả để bỏ lọc.
- Game chưa có thể loại sẽ nằm ở nhóm Khác.
- Góc phải hàng tìm kiếm cho biết vị trí game đang chọn, ví dụ 12 / 340.

## 3. Chọn phiên bản và tải patch
- Chọn game trong Kho Việt Hóa rồi bấm A để mở trang chi tiết.
- Một game có thể có nhiều bản patch cho từng phiên bản game khác nhau.
- Kiểm tra phiên bản game của bạn: ở màn hình chính Switch, bấm + trên game, xem dòng phiên bản.
- Game có nhiều bản: bấm A sẽ hiện bảng Chọn phiên bản game của bạn.
- Dùng lên/xuống để chọn đúng phiên bản, bấm A để tải, bấm B để đóng bảng.
- Có thể chạm vào một dòng để chọn, chạm lần nữa để tải.
- Bản có nhãn cam Cần DLC nghĩa là phải cài DLC đúng phiên bản đó thì patch mới chạy.
- Dòng Yêu cầu màu cam trong trang chi tiết là lưu ý chung của game, đọc kỹ trước khi tải.
- Tải sai phiên bản có thể làm game lỗi hoặc không hiện tiếng Việt.
- Đang tải mà muốn hủy thì bấm B. Phần đã tải được giữ lại, lần sau tải tiếp từ chỗ dừng.
- Có thể về Trang chủ trong lúc tải, tiến trình vẫn hiện ở góc trên bên phải.
- Patch tải xong sẽ được giải nén tự động.

## 4. Cài việt hóa vào game
- Yêu cầu: máy Switch đã chạy CFW (Atmosphère hoặc SX OS). Máy chưa mod thì không cài được.
- Thư mục chép việt hóa: Atmosphère là sdmc:/atmosphere/contents, SX OS là sdmc:/sxos/titles.
- Các bước dưới đây dành cho Atmosphère. Dùng SX OS (máy v2 hoặc Lite) thì xem thêm mục 5.
- Patch tải về nằm ở sdmc:/switch/SWITCH-VIET-HOA-STORE/patches, bản giải nén nằm ở sdmc:/switch/SWITCH-VIET-HOA-STORE/extracted.
- Bước 1: Vào mục Đã Tải (app tự mở sẵn thư mục giải nén), mở thư mục của game vừa tải.
- Bước 2: Bên trong là thư mục Title ID của game (16 ký tự, ví dụ 0100F2C0115B6000).
- Khi giải nén, app tự bỏ các thư mục thừa phía trước (tên game, atmosphere/contents...) và các file ngoài lề như readme, chỉ giữ từ thư mục Title ID trở đi.
- Bước 3: Đưa con trỏ tới thư mục Title ID, bấm Y để mở menu lệnh, chọn Copy.
- Bước 4: Đi tới sdmc:/atmosphere/contents (SX OS là sdmc:/sxos/titles), bấm Y chọn Dán.
- Đã có bản cũ thì cứ dán đè, app tự gộp thư mục và ghi đè file trùng.
- Bước 5: Thoát app, tắt game nếu đang mở rồi mở lại game. Nếu chưa thấy tiếng Việt thì khởi động lại máy.
- Cài nhanh không cần chép: vào Cài Đặt, chọn Thư mục giải nén là sdmc:/atmosphere/contents (SX OS là sdmc:/sxos/titles). Từ đó tải xong là app chép thẳng thư mục Title ID vào đó, bỏ qua Bước 1 đến 4.
- Gói patch không có thư mục Title ID thì app vẫn giải nén vào sdmc:/switch/SWITCH-VIET-HOA-STORE/extracted để bạn tự xem và chép.
- Lưu ý: phiên bản game phải đúng với phiên bản patch. Cập nhật game lên bản mới có thể làm patch không chạy, khi đó tải lại patch đúng phiên bản.
- Patch có nhãn Cần DLC thì phải cài DLC đúng phiên bản đó trước.
- Gỡ việt hóa: vào sdmc:/atmosphere/contents, xóa thư mục Title ID của game rồi mở lại game.
- Cẩn thận: không xóa nhầm thư mục Title ID của mod hoặc cheat khác.

## 5. Máy chạy SX OS (v2 hoặc Lite)
- Chép thư mục Title ID của game vào sdmc:/sxos/titles (thay cho atmosphere/contents).
- SX OS bản beta chưa hỗ trợ LayeredFS (trình nạp mod game), nên phải mở mục Cheats một lần để SX OS nhận thư mục titles của game.
- Game dạng XCI: chép game và chép việt hóa vào máy, rồi mở game.
- Nếu chưa thấy tiếng Việt: bấm Home ra màn hình chính, vào Album, chọn Cheats, rồi bấm Home ra màn hình chính lần nữa.
- Tắt hẳn game (bấm X trên game, chọn Đóng), khởi động lại máy rồi mở game, lúc này sẽ có tiếng Việt.
- Game dạng NSP: cài game trước, CHƯA chép việt hóa.
- Mở game một lần rồi làm như dạng XCI ở trên (Home, Album, Cheats, Home, tắt game).
- Làm xong các bước đó mới chép việt hóa vào sdmc:/sxos/titles, khởi động lại máy rồi mở game.

## 6. Tránh crash khi chơi game việt hóa
- Patch việt hóa thay đổi file game nên dễ xung đột với ứng dụng chạy ngầm (sysmodule) và ép xung (OC).
- Bị crash, đơ, màn hình đen hoặc báo lỗi Atmosphère thì làm lần lượt các bước dưới đây.
- Tắt ép xung: nếu dùng sys-clk, mở overlay (thường bấm L + D-pad xuống + R3) hoặc app sys-clk manager, đưa CPU/GPU/RAM về mặc định (Do not override) hoặc tắt sys-clk.
- Tắt sysmodule bằng overlay: mở Tesla/Ultrahand (L + D-pad xuống + R3), vào mục Sysmodules, tắt các mục không cần như sys-clk, MissionControl, ldn_mitm, emuiibo, sys-con, sys-ftpd.
- Tắt sysmodule bằng tay: vào mục Đã Tải, mở sdmc:/atmosphere/contents. Mỗi sysmodule là một thư mục Title ID có chứa thư mục flags.
- Mở thư mục flags, đổi tên file boot2.flag thành boot2.flag.bak (bấm Y, chọn Đổi tên). Muốn bật lại thì đổi tên về như cũ.
- Không đổi tên hay xóa thư mục Title ID của game (thư mục có romfs hoặc exefs), đó là chính bản việt hóa.
- Tắt cheat: không bật cheat (EdiZon, Breeze, thư mục cheats) cùng lúc với bản việt hóa.
- Tắt sysmodule xong phải khởi động lại máy (Restart) thì mới có tác dụng.
- Đóng hẳn game trước khi chép hoặc xóa patch: bấm Home, bấm X trên game, chọn Đóng.
- Vẫn crash thì kiểm tra lại phiên bản game, DLC, hoặc thử tải lại patch vì file có thể bị hỏng khi tải.

## 7. Quản lý file (mục Đã Tải)
- Mục Đã Tải duyệt được toàn bộ thẻ SD: A mở thư mục, B lên thư mục cha, X chọn hoặc bỏ chọn một mục.
- Bấm Y để mở menu lệnh: Copy, Cắt / Di chuyển, Dán, Xóa, Đổi tên, Tạo thư mục mới, Chọn tất cả.
- Chọn nhiều mục bằng X rồi bấm Y để copy, di chuyển hoặc xóa cùng lúc.
- Ở thư mục gốc thẻ SD, bấm B để về Trang chủ.

## 8. Chia sẻ bản việt hóa
- Ở Trang chủ chọn ô Chia Sẻ, điền lần lượt từng mục rồi bấm Gửi.
- Tên game: bấm A để gõ. Nên gõ chữ không dấu, đúng tên gốc của game.
- Bỏ trống tên game thì app tự lấy tên file hoặc thư mục bạn đã chọn.
- Ví dụ đúng: Super Mario Odyssey. Ví dụ sai: Mario Odyssey Viet Hoa v1.
- Chỉ gõ tên game, không thêm chữ việt hóa, số phiên bản hay dấu đặc biệt vào tên.
- Phiên bản: gõ số phiên bản game mà bản việt hóa hỗ trợ, ví dụ 1.0 hoặc 1.2.3.
- Phiên bản chỉ gồm số, chữ cái và dấu chấm. Không gõ chữ v ở đầu.
- Thể loại: bấm A để đổi qua lại giữa các thể loại, chọn đúng thể loại của game. Thể loại này dùng cho bảng lọc ở Kho Việt Hóa.
- Chọn Tự động thì thể loại lấy theo dữ liệu IGDB, có thể không chính xác.
- Tác giả việt hóa (không bắt buộc): gõ tên bạn nếu muốn, tên sẽ hiện trên kho game và hàng Mới cập nhật cho mọi người.
- Nút Gửi lên nằm góc trên bên phải, hoặc bấm X ở bất kỳ dòng nào để gửi ngay.
- Title ID (không bắt buộc): gồm đúng 16 ký tự số 0-9 và chữ A-F, ví dụ 01006BB00C6F0000.
- Không biết Title ID thì để trống. Gõ sai độ dài thì app sẽ báo lỗi và xóa đi.
- Mô tả ngắn (không bắt buộc): 1-2 câu về bản việt hóa, ví dụ: Việt hóa toàn bộ hội thoại và menu.
- Để trống mô tả thì app tự lấy mô tả của game từ IGDB.
- File patch: chọn file .zip, .7z hoặc .rar trên thẻ SD, tối đa 1 GB.
- Nếu bản việt hóa là thư mục: di chuyển con trỏ tới thư mục đó rồi bấm X để chọn.
- App tự nén thư mục thành .zip rồi gửi, bạn không cần nén trước. Đừng chọn cả thẻ SD.
- Tên file trên thẻ SD đặt gì cũng được, app tự đổi thành tên chuẩn khi gửi.
- Tên chuẩn có dạng: ten-game__v1.0.zip (ví dụ: super-mario-odyssey__v1.0.zip).
- Bên trong file nén nên giữ đúng cấu trúc thư mục cần chép vào thẻ SD.
- Game đã có trên Kho hoặc đang chờ duyệt thì không gửi lại được.
- Đang gửi mà muốn hủy thì bấm B.
- Gửi xong, bản việt hóa sẽ hiện ở Kho Việt Hóa sau khi được duyệt.

## 9. Cài đặt
- Mục Cài Đặt cho phép chọn thư mục tải patch, thư mục giải nén, tải lại danh sách game.
- Sau khi giải nén xong: bấm A để đổi giữa Giữ file nén (xem lại ở Đã Tải > Đã tải) và Xóa file nén (tiết kiệm thẻ SD). App lưu lựa chọn ngay.
- Chọn thư mục bằng hộp duyệt thẻ SD: A mở thư mục, X chọn thư mục đang mở, Y tạo thư mục mới, B lên thư mục cha.
- Mục Cập nhật ứng dụng dùng để tải bản mới nhất của app, xong cần mở lại app.
- Có bản mới thì ô Cài Đặt ở Trang chủ ghi Có bản cập nhật mới, và app hỏi bạn có muốn cập nhật ngay không.
- Thông tin phiên bản, tác giả được lưu tạm 1 giờ. Mới cập nhật trên kho thì có thể chờ tối đa 1 giờ mới thấy.

## 10. Thoát ứng dụng
- Bấm + ở bất kỳ màn hình nào (hoặc chạm nút + Thoát ở thanh dưới), rồi chọn Có để thoát.
